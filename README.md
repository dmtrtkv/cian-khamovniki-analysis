# Анализ рынка квартир района Хамовники (Москва) по данным ЦИАН

Учебный проект по дисциплине «Особенности сбора образовательных данных», 4 курс.
Команда — 4 человека.

## Задача

Собрать с ЦИАН цены на квартиры в районе Хамовники по 6 подзапросам
(2 категории × 3 подкатегории), проанализировать и рассчитать **точку
окупаемости** — за сколько месяцев сдача квартиры окупает её покупку.

| | 1-комнатные | 2-комнатные | 3+ комнатные |
|---|---|---|---|
| **Аренда (долгосрочная)** | подзапрос 1 | подзапрос 2 | подзапрос 3 |
| **Продажа** | подзапрос 4 | подзапрос 5 | подзапрос 6 |

## Быстрый старт

```bash
pip install pandas matplotlib seaborn numpy scipy openpyxl curl_cffi

python main.py              # весь цикл: сбор -> очистка -> анализ -> графики
python main.py --no-parse   # то же на сохранённых данных, без обращений к ЦИАН
```

`--no-parse` нужен потому, что ЦИАН ограничивает частоту запросов. Сырые ответы
сохранены в `data/raw/*.json`, и все таблицы с графиками пересобираются из них.

Отдельные этапы, если нужно:

```bash
python src/parse.py --rooms all --deal both   # сбор данных с ЦИАН
python src/reflatten.py                       # пересборка таблиц из JSON
python src/clean.py                           # очистка и сведение таблицы
python src/analyze.py                         # расчёты и графики
```

Сбор можно разделить между участниками команды:

```bash
python src/parse.py --rooms 1        # участник 1: однокомнатные
python src/parse.py --rooms 2        # участник 2: двухкомнатные
python src/parse.py --rooms 3plus    # участник 3: трёх- и более комнатные
```

## Структура

```
├── LOG.md                    рабочий журнал: что делали, какие проблемы, как решали
├── main.py                   единая точка входа: весь цикл одной командой

│   ├── cian_api.py           клиент JSON-API ЦИАН (пагинация, повторы, деление по цене)
│   ├── parse.py              сбор объявлений и разбор в плоскую таблицу
│   ├── reflatten.py          пересборка CSV из сохранённых JSON без запросов к сайту
│   ├── clean.py              очистка, дедупликация, отсев выбросов
│   └── analyze.py            статистика, точка окупаемости, 11 графиков
├── data/raw/                 сырые выгрузки по каждому подзапросу (JSON + CSV)
├── data/processed/           итоговая таблица и результаты расчётов
├── figures/                  графики
└── report/                   материалы отчёта
```

## Итог

Собрано **1189** объявлений, после очистки — **1144**. Все 6 подкатегорий
проходят требование «не менее 50 объявлений».

Ключевой результат — точка окупаемости. Основной расчёт выполнен на полной
выборке, включая новостройки и котлован, как требует задание:

| Подкатегория | **Основной расчёт** | Доходность |
|---|---|---|
| 1-комнатные | **73.2 года** | 1.37% годовых |
| 2-комнатные | **75.0 лет** | 1.33% годовых |
| 3+ комнатные | **50.9 года** | 1.96% годовых |

Дополнительно проверили, почему доходность вышла настолько низкой. Оказалось,
что в Хамовниках продаются преимущественно элитные новостройки, а сдаётся
обычный вторичный фонд — то есть числитель и знаменатель формулы относятся
к разным сегментам рынка. Если привести выборки к сопоставимому виду:

| Подкатегория | Сопоставимая оценка | Доходность |
|---|---|---|
| 1-комнатные | 27.2 года | 3.67% годовых |
| 2-комнатные | 35.1 года | 2.85% годовых |
| 3+ комнатные | 43.4 года | 2.31% годовых |

Это не замена основному расчёту, а его объяснение. Подробности — в
[LOG.md](LOG.md), этап 8.
