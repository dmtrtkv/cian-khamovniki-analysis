# Анализ рынка квартир района Хамовники (Москва) по данным ЦИАН

Учебный проект по дисциплине «Особенности сбора образовательных данных», 4 курс.
Команда — 4 человека.

## Задача

Собрать с ЦИАН цены на квартиры в районе Хамовники по 6 подзапросам
(2 категории × 3 подкатегории), проанализировать и рассчитать **точку
окупаемости** — за сколько месяцев сдача квартиры окупает её покупку.

| | 1-комнатные | 2-комнатные | 3+ комнатные |
|---|---|---|---|
| **Аренда (долгосрочная)** | подзапрос 1 | подзапрос 2 | подзапрос 3 |
| **Продажа** | подзапрос 4 | подзапрос 5 | подзапрос 6 |

## Быстрый старт

```bash
pip install pandas matplotlib seaborn numpy scipy openpyxl curl_cffi

python src/parse.py --rooms all --deal both   # сбор данных с ЦИАН
python src/clean.py                           # очистка и сведение таблицы
python src/analyze.py                         # расчёты и графики
```

Сбор можно разделить между участниками команды:

```bash
python src/parse.py --rooms 1        # участник 1: однокомнатные
python src/parse.py --rooms 2        # участник 2: двухкомнатные
python src/parse.py --rooms 3plus    # участник 3: трёх- и более комнатные
```

## Структура

```
├── LOG.md                    рабочий журнал: что делали, какие проблемы, как решали

│   ├── cian_api.py           клиент JSON-API ЦИАН (пагинация, повторы, деление по цене)
```

## Итог

Собрано **1189** объявлений, после очистки — **1144**. Все 6 подкатегорий
проходят требование «не менее 50 объявлений».

Ключевой результат — точка окупаемости:

| Подкатегория | Наивный расчёт | Сопоставимая оценка | Доходность |
|---|---|---|---|
| 1-комнатные | 73.2 года | **27.2 года** | 3.67% годовых |
| 2-комнатные | 75.0 лет | **35.1 года** | 2.85% годовых |
| 3+ комнатные | 50.9 года | **43.4 года** | 2.31% годовых |

Наивная формула «средняя цена продажи / средняя ставка аренды» завышает срок
в 1.2–2.7 раза: в Хамовниках продаются в основном элитные новостройки,
а сдаётся обычный вторичный фонд. Подробности — в [LOG.md](LOG.md), этап 8.
